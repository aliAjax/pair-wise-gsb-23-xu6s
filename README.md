# hxwl-09 半导体洁净室周转台

洁净换线时晶圆载具的登记、准入判断与留档看板。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 周转规则

- 每个载具登记编号、等级、清洗周期、上次合格清洗时刻与清洗批次。
- 未卸片（或仍绑定批次）的载具不得再次分配，分配被拦截并留档。
- 清洗周期过期的载具自动停在待洗区，不可分配。
- 清洗完成须记录清洗批次、残留检测与湿度复测，两项均合格才回可用区；任一不合格留在待洗区返洗。
- 退回或取消批次须填写原因后释放载具，动作写入留档。
- 检测更正另写更正事件与原因，指向原记录，旧值不覆盖。

## 代码分层（`src/carrier/`）

- `types.ts`：载具资料、状态与留档事件模型。
- `admission.ts`：准入判断（过期、分配拦截、洗后回区），纯函数。
- `archive.ts`：留档事件追加与更正链查询，只追加不改写。
- `store.tsx`：载具周转状态机与页面状态供给。
- `seed.ts`：演示台账（事件回放构造初始状态）。
- `components/`：登记面板、四区看板、载具卡片与留档面板。
