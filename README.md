# hxwl-09 晶圆载具周转台

洁净室换线看板：晶圆载具（FOUP 等）登记、分配拦截、清洗准入与留档。

## 技术栈

React + Vite + TypeScript + CSS（无额外运行时依赖，数据存浏览器 localStorage）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 周转规则

1. **登记**：每个载具登记编号、洁净等级、清洗周期、上次清洗时刻；编号唯一。
2. **分配拦截**：载具仍装载批次（未卸片）时禁止再次分配；清洗周期已过则停在**待洗区**，不放行。
3. **清洗回区**：待洗区载具洗完后登记对应批次、残留检测、湿度复测与完成时刻；**两项同时合格**才回可用区，任一不合格继续停留待洗区重洗。
4. **卸片 / 退回 / 取消**：卸片后按清洗是否过期自动归入可用区或待洗区；批次退回、取消会释放载具并强制留下说明记录。
5. **结果更正**：检测结论更正必须填写原因，作为更正条目追加保存，**原始值不覆盖**；准入判断按最近一次更正后的现行值执行。

## 三层分离

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 载具资料 | `src/carrier/registry.ts` | 在册封皮、清洗记录数据结构、登记规则、演示种子 |
| 准入判断 | `src/carrier/eligibility.ts` | 分区推导、过期计算、分配拦截、双检合格判定（纯函数） |
| 留档 | `src/carrier/archive.ts` | append-only 事件流（登记/分配/卸片/清洗/退回取消/更正），可导出 JSON |

状态与持久化在 `src/carrier/store.ts`，界面在 `src/components/` 与 `src/App.tsx`。
